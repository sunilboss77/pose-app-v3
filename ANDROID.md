# Android build notes

The Android project in `android/` targets Capacitor 8 and keeps the web app's
CSS/SystemBars edge-to-edge handling. The removed legacy margin-adjustment
setting is not used.

## Toolchain

- Node.js 22 or newer (Capacitor 8 requirement)
- JDK 21
- Android Studio Otter (2025.2.1) or newer
- Android SDK Platform 36 and Build Tools 36
- Android API 24 remains the minimum supported API

Install Java/Android tooling through Android Studio or your normal system
package manager; this repository does not install system tools.

## Build and sync

From the repository root:

```bash
pnpm install
pnpm build:mobile
pnpm cap sync android
```

The mobile build requires `NEXT_PUBLIC_API_BASE_URL` to be set to the deployed
API origin. Open the native project with Android Studio by opening the
`android/` directory, then select a device/API 24+ emulator and run the app.

The native Capacitor wiring files are generated by `cap sync`. If dependencies
are freshly installed, run `pnpm cap sync android` again so the generated
plugin modules and copied `out/` assets match the installed packages.

## Release signing

No signing secrets, keystores, or passwords are committed. Configure signing
in Android Studio or in CI using secret environment variables such as:

```text
POSE_GUIDE_KEYSTORE_PATH
POSE_GUIDE_KEYSTORE_PASSWORD
POSE_GUIDE_KEY_ALIAS
POSE_GUIDE_KEY_PASSWORD
```

Use a local `*.jks`/`*.keystore` file only; the repository ignores those file
types. Keep release signing values in the CI secret store and inject them into
the Gradle release configuration there.

## Play Console checklist

1. Build a signed Android App Bundle (`bundleRelease`) with the final version
   code and release application ID.
2. Complete the Play Console Data safety and privacy declarations, including
   camera and microphone use.
3. Upload the AAB to an internal testing track first, test on API 24+ devices,
   then promote through closed/open testing as appropriate.
4. Add store listing artwork, screenshots, content rating, app access details,
   and the public privacy policy before production rollout.
